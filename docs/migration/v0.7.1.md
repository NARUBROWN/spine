# v0.7.1 긴급 패치

`v0.7.0`에서 누락된 다중 스칼라 경로 인자 배정을 수정합니다. `/:id/:name`은 `input.Path[int64]`, `input.Path[string]`에 라우트 순서대로 값을 배정합니다. Context, Query와 Body 인자는 경로 배정 순서에서 제외합니다.

경로 변수와 스칼라 인자의 수가 다르거나 스칼라와 경로 DTO 또는 기존 path 래퍼를 섞으면 초기화 전에 거부합니다. 기존 단일 스칼라와 경로 DTO는 계속 사용할 수 있습니다. 잘못된 값과 정수 범위 초과는 HTTP 400입니다. Echo와 net/http 및 런타임 OpenAPI가 같은 배정 규칙을 사용합니다.

새 공개 계약이나 플랫폼 소스 변경은 없습니다. 기존 플랫폼 태그를 재사용하고 코어 릴리스에서 전체 조합을 검증합니다. 플랫폼이 선언한 최소 코어 의존 버전을 올리거나 플랫폼을 다시 발행할 필요는 없습니다.

CLI의 다중 스칼라 최소 지원 코어 버전은 실제 수정이 포함된 `v0.7.1`에 맞춰야 합니다. 기존 CLI가 `v0.7.0-preview.9`부터 지원한다고 표시하더라도 `v0.7.0`에는 이 수정이 없습니다.

[경로 입력 작성 예](controller-routes.md#스칼라-경로-값)와 [기존 v0.7.0 전환 안내](v0.7.0.md)를 참고하세요. 이 문서는 패치 후보의 설명이며 공개 발행 완료 여부는 태그와 Actions 검증 기록을 확인하세요.

## v0.7.0 철회

`v0.7.1`의 go.mod는 다중 스칼라 경로 입력이 누락된 `v0.7.0`을 retract로 철회합니다. 철회 정보가 공개되면 일반적인 최신 버전 선택에서 제외됩니다. 이미 고정한 의존성이나 명시적인 `@v0.7.0` 다운로드는 자동으로 차단되지 않으므로 `v0.7.1` 이상으로 갱신하세요. 기존 태그와 체크섬은 변경하지 않습니다.
