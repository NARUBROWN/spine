# Historical migration: v0.7.0

This migration introduced HTTP v3 raw input, controller route callbacks, constructor roles, managed HTTPS and runtime OpenAPI opt-in. HTTP route options use `path, handler, options...`; `api.OptionSet` and `api.Options` were removed.

Use `RegisterRoutes`, explicit input wrappers and role-marked constructors in new applications. Runtime OpenAPI is enabled with `OpenAPI.Enabled`, not by setting a title. Platform versions remain independent of the core release number.

The original v0.7.0 release was retracted because multiple scalar path inputs were missing. See [v0.7.1](v0.7.1.md), [v0.7.2](v0.7.2.md), the [Korean original](../ko/migration/v0.7.0.md) and [current source migration](v0.7.6.md).
