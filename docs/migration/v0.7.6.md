# Spine v0.7.6 마이그레이션

서비스에서 `publish.Event(ctx, destination, publish.Fields{...})`로 JSON 이벤트를 발행 대기열에 등록합니다. 기존 구조체 기반 이벤트는 `publish.DomainEvents(ctx, event)`로 등록합니다. Kafka, RabbitMQ와 NATS에서 발행을 켜면 어댑터 설정의 `PublishDestinations`에 논리 목적지 목록을 제공해야 합니다.

초기화가 실패할 수 있는 DI 생성자는 값과 `error`를 반환할 수 있습니다. 앱 종료 시 DI 서비스 정리가 필요하면 `spine.WithShutdownHook`에 종료 콜백을 등록합니다.

검증기가 조건부 필수 규칙을 제공하면 OpenAPI는 요청 스키마에 `if`와 `then`을 표시합니다.
