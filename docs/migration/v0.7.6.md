# Spine v0.7.6 마이그레이션

이벤트 발행은 앱 수명의 DI `publish.Publisher`로 통합합니다. `publisher.Event(ctx, destination, publish.Fields{...})`는 즉시 전송하고 플랫폼 결과를 반환합니다. 기존 패키지 함수와 실행별 EventBus 및 drain 경로는 제거했습니다. 발행 성공 후 핸들러나 응답 처리가 실패해도 전송은 유지됩니다. 호출 변경, Outbox 메타데이터와 종료 순서는 [DI Publisher 마이그레이션](app-publisher.md)을 참고하세요.

Kafka, RabbitMQ와 NATS에서 발행을 켜면 어댑터 설정의 `PublishDestinations`에 논리 목적지 목록을 제공해야 합니다.

초기화가 실패할 수 있는 DI 생성자는 값과 `error`를 반환할 수 있습니다. 앱 종료 시 DI 서비스 정리가 필요하면 `spine.WithShutdownHook`에 종료 콜백을 등록합니다.

검증기가 조건부 필수 규칙을 제공하면 OpenAPI는 요청 스키마에 `if`와 `then`을 표시합니다.
