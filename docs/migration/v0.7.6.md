# Migrate to the v0.7.6 source API

This branch targets `v0.7.6` and extends the tagged `v0.7.6-preview.1` source. The branch's new APIs are not implied to exist in that previously published tag. Verify the exact source or released module combination you install.

| Area | Required change |
| --- | --- |
| Publishing | Inject `publish.Publisher`; handle the synchronous `Event` error. Remove package-level publishing and EventBus/drain code. |
| HTTP context | Use `spine.Ctx` views; runtime owns one `execution.Context` with State and direct Input fields. |
| WS callbacks | Register `r.WS` with `input.Message[T]` and `context.Context` or `spine.WebSocketCtx`. Inject `ws.Sender`. |
| WS hooks | Register message and upgrade hooks separately; rename `PreHandshake` to `BeforeUpgrade`. |
| Event consumers | Use `spine.EventCtx`; retain subscription-based routing and runtime-owned settlement. |
| Documentation | English defaults live under `docs/`; Korean originals live under `docs/ko/`. Only the root README and agent rules remain outside docs. |

Read [Publisher migration](app-publisher.md), [HTTP context ownership](http-context.md), [WS callbacks and hooks](websocket-dx.md), [context lifetimes](../guides/contexts.md) and [runnable examples](../examples/demo.md).

`cmd/demo` and `cmd/reference` demonstrate current composition. Validate source candidates with race tests and real HTTP/WS traffic. Optional broker tests need explicit endpoints. Source-workspace validation is separate from public-tag installation and release promotion.
