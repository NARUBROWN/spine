# Historical migration: v0.7.2

Replace plain HTTP DTO pointers with `input.Body[T]`, `input.Query[T]`, `input.Header[T]` and `input.Path[T]`. Plain parameters fail with `HTTP_INPUT_WRAPPER_REQUIRED`. Tags continue to select field names; scalar path inputs remain supported.

`input.Header[T]` provides explicit header-source binding and shares conversion, validation and description rules with runtime OpenAPI. Body wrappers support JSON, XML, form and multipart. File headers remain valid only during the request.

The incomplete v0.7.2-preview.1 candidate and header-incomplete v0.7.1 are retracted in go.mod. Published tags and checksums are not changed. An installed CLI must separately support the selected core's wrappers.

See [structured inputs](structured-inputs.md), the [Korean original](../ko/migration/v0.7.2.md) and [current source migration](v0.7.6.md).
