# Historical migration: v0.6.5

This release separated HTTP, WebSocket, event and validation contracts from concrete platforms. Core uses standard-library contracts; applications select independent implementations.

Move broker addresses and credentials from removed broker-specific boot options into platform Config values. Register factories with `WithEventAdapter`; common retry and settlement policy remains in core options. HTTP-less workers omit HTTP and WS integrations.

Use `WithValidator` for optional DTO validation. Binding failures and validator execution errors are distinct from rule violations. New platform code uses canonical `contract/` imports.

The original migration text is preserved in [Korean](../ko/migration/v0.6.5.md). For this source branch's current context, publisher and WS APIs, continue to [v0.7.6](v0.7.6.md). Published historical tags retain their original layout.
