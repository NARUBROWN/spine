# Spine v0.6.6 전환 예정

현재 main은 다음 패치 버전인 v0.6.6을 준비합니다. v0.6.6 태그와 GitHub 릴리스는 아직 발행하지 않았습니다.

## WebSocket 호환 경로 정리

루트의 `wsadapter` 패키지를 `adapter/websocket`으로 옮겨 HTTP와 이벤트 호환 경로와 같은 디렉터리 아래에서 관리합니다.

| v0.6.5 import | 현재 main의 import |
| --- | --- |
| `github.com/NARUBROWN/spine/wsadapter` | `github.com/NARUBROWN/spine/adapter/websocket` |

기존 경로를 사용한 코드는 import를 바꿔야 합니다. 새 구현은 정식 계약인 `github.com/NARUBROWN/spine/contract/websocket`을 사용합니다.

타입과 오류의 동일성, 종료 코드, `spine.websocket-adapter/v1` 계약 버전과 실행 동작은 그대로입니다. 정식 계약을 사용하는 Gorilla 플랫폼과 앱에는 import 수정이 필요하지 않습니다. 이미 공개한 v0.6.5 태그는 변경하지 않습니다.

자세한 계약은 [WebSocket 계약](../../contract/websocket/README.md), 호환 경로는 [adapter/websocket](../../adapter/websocket/README.md)을 참고하세요.
