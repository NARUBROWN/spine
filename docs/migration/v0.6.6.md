# Historical migration: v0.6.6

The root `spine/wsadapter` compatibility package moved to `spine/adapter/websocket`. New code should use `spine/contract/websocket` directly. Prefix imports with `github.com/NARUBROWN/`.

The move preserved type/error identity and the `spine.websocket-adapter/v1` contract. Existing v0.6.5 tags are not rewritten.

See [compatibility imports](../reference/adapter-compatibility.md), the [Korean original](../ko/migration/v0.6.6.md) and [current source migration](v0.7.6.md).
