# Select an independent WebSocket platform

Applications with WebSocket routes select HTTP and WebSocket implementations separately. The standard-library contract is `contract/websocket`, identified by `spine.websocket-adapter/v1`. The external [spine-gorilla-platform](https://github.com/NARUBROWN/spine-gorilla-platform) implements it. The core module has no external dependencies.

```go
app := spine.New(
    echoPlatform.Option(),
    gorillaPlatform.Option(),
    spine.WithEventAdapter("events", factory),
    spine.WithValidator(validator),
)
```

Use the Echo and Gorilla module imports for the two platform aliases. Create the event factory with `NewFactory(config)` and the validator with `playground.New()`, returning their errors before constructing the app. Existing event/validator APIs, constructors, routes and consumer registrations remain the same. HTTP-only applications omit the Gorilla option and module. HTTP-less workers omit both transport options. WebSocket routes require HTTP upgrade support and an explicit WebSocket factory; missing selection fails before initialization.

The kernel retains authentication, origins/trusted proxies, capacity, serialized writes, ping scheduling and shutdown. The platform owns native upgrade, read limits/deadlines and control frames. A new read deadline starts after handler execution. Rule failures close with 1008, processing failures with 1011, and normal server shutdown with 1000. See the [contract reference](../../contract/websocket/README.md).

The public development combination is Spine `v0.6.1-0.20261103040400-9b1321410211`, Echo platform `v0.1.0`, and Gorilla platform `v0.0.0-20261103040512-36ad41dff88f`. These published pseudo-versions are separate from a merged PR or final release tag. Core/Gorilla require Go 1.25.5; the current playground implementation requires Go 1.26+.

The CLI PR #28 generator supports `--websocket-platform none|gorilla`, defaulting to `none`. Gorilla requires HTTP Echo. Check the installed CLI with `spine schema --json` before using this option. `spine update` changes dependencies only; it does not insert WebSocket options or migrate source. Review explicit WS selection before manually moving an existing app to the separated core.

Run core race tests and `scripts/check-module-boundaries.sh`, then the `test` and `cmd/demo` module suites. [Platform E2E](../../test/platform-e2e/README.md) covers the actual broker combination. The CLI repository's `test/assembly-e2e/README.md` describes tests of applications generated by the real CLI. Keep static analysis, local-source tests, public-module installation and live-broker evidence distinct.
