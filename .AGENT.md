# Working rules

- Do not use middle dot punctuation in deliverables.
- Use the user's verified Git identity for both Author and Committer.
- Never register Codex, OpenAI or another AI agent as a commit author or co-author.
- Do not add AI contributor trailers such as `Co-authored-by`, `Co-developed-by` or `Assisted-by` to commit messages.
- Before pushing, inspect the resulting author, committer and commit message and verify that no AI contributor attribution was added.
- Keep Markdown documentation under `docs/`. Only root `README.md`, `AGENTS.md` and `.AGENT.md` are exceptions.
- Write default documentation in English. Keep Korean originals under `docs/ko/`.
